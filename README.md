## New-Project Repository

This repository contains the initial project setup. Below are instructions for developers on how to continue working with the repository.

---

## How to start working with the repository?

### 1. Clone the repository

```bash
git clone https://github.com/srhov/new-project.git
cd new-project
```

### 2. Switch to the development branch

```bash
git checkout development
```

### 3. Make changes to the project

Edit files in your editor or IDE.

After making changes:

```bash
git add .
git commit -m "PROM-**** #comment description of your changes"
```

### 4. Push changes to the remote repository

```bash
git push origin development
```
